# My Life

> The story will start again, but this time the character will be different.

I'm starting over.

I don't really know exactly where I'm going yet, but I know what I want to do. I want to learn, build things, break things, fix them, and keep getting better at what I do.

I'm keeping my identity anonymous. For now, I want people to see what I build before they know who I am.

I spend a lot of my time messing around with technology. I like coding, AI, Linux, cybersecurity, automation, hardware, and pretty much anything that makes me think, *"wait, how does this actually work?"*

I don't want to just watch tutorials, read about things, or collect skills.

I want to actually use what I learn.

If I learn something, I want to try building something with it. If something doesn't work, I'll figure out why. If I mess something up, I'll try again.

I'm probably going to make a lot of bad projects.

I'll probably abandon some of them.

I'll probably look back at some of my old code and wonder what the hell I was thinking.

And that's fine.

I want this repository to be a place where I can keep all of it — what I'm building, what I'm learning, the experiments I'm doing, the mistakes I make, and the things I'm proud of.

I don't have some perfect five-year plan.

Right now, I just want to keep learning and keep building until I make something that is genuinely useful.

Maybe this turns into something big.

Maybe it doesn't.

I'll find out.

**This is my starting point.**

The old me stays buried.

— Anonymous
